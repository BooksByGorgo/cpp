# How to use this booklet

This is a short booklet to help a Java programmer get up to speed with C.
As a side benefit, you will probably find that you understand Java better at the end of it --- seeing where Java came from makes a lot of its design choices click into place.

Each chapter is meant to help you understand a topic, but you will still want to reference API descriptions for more specifics of the parameters and operating conditions.
Hopefully you will have the context you need to understand API documentation.

## Tips

Throughout this booklet you will see three kinds of callout boxes:

::: {.tip}
**Tip:** A **Tip** calls out an idiom, best practice, or something worth paying special attention to.
:::

::: {.tip}
**Trap:** A **Trap** warns you of a common mistake.
C will let you make it; your compiler may not even warn you; and the bug may not show up until runtime.
:::

::: {.tip}
**Wut:** A **Wut** flags something counter-intuitive --- a rule that surprises almost everyone the first time they see it.
:::

## Try It

Remember:

> The only way to learn a new programming language is by writing programs in it.

You need to write some code.
Make sure you try writing some programs from scratch.
At the end of most chapters is a starter program that you can type in and experiment with.
Do not use it as an excuse to avoid writing some of your own programs.
It is the only way to master a language.

## Chapter Layout

Each chapter follows a consistent structure:

- A **brief overview** at the top that sets the context and lists what the chapter covers.
- The **main content** with explanations, code examples, and callouts (Tips, Traps, and Wuts).
- A **Try It** starter program you can compile and modify.
- **Key Points** summarizing the most important takeaways.
- **Exercises** with a mix of questions to test your understanding.

## Exercises

Do not skip the exercises at the end of the chapters.
An answer key is available, but do not look at it before you work out the answer yourself.
If you look at the answer key first, the concepts will not sink in.
