# project description

lulu executive book build for `Gorgo Starting C++ and C`. produces the combined interior PDF (`lulu-sc++c.pdf`), the wraparound cover PDF (`lulu-cover.pdf`), an sc++-only interior (`sc++-lulu.pdf`), and a c4c++-only interior (`c4c++-lulu.pdf`), each with a matching standalone cover.

## building

run `make` in sc++c/ to build the combined interior and cover PDFs. the Makefile automatically injects the last commit date as the subtitle.

- `make lulu-sc++c.pdf` --- combined interior only
- `make lulu-cover.pdf` --- cover only
- `make sc++-lulu.pdf` --- sc++-only interior with index (not part of `make all`)
- `make lulu-cover-sc++.pdf` --- cover for the sc++-only book (not part of `make all`)
- `make c4c++-lulu.pdf` --- c4c++-only interior with index (not part of `make all`)
- `make lulu-cover-c4c++.pdf` --- cover for the c4c++-only book (not part of `make all`)
- `make bowker` --- front-cover JPGs of all three books (7x10in trim, 300 DPI) for bowker ISBN registration; the crop offset is computed from each cover's width so it survives spine-width changes (not part of `make all`)
- `make clean` --- remove all build artifacts

## interior (`lulu-sc++c.pdf`)

- combines sc++ (Starting C++) and c4c++ (C for C++ Programmers) into one book; the c4c++ part is the full book including the conclusion and appendix A
- lulu executive trim: 7x10in (paperwidth=7in, paperheight=10in)
- margins: inner=0.8in, outer=0.7in, top=0.6in, bottom=0.9in, footskip=0.3in (footer must stay 0.5in+ from the trim edge for lulu; text height is 8.5in --- changing it reflows pages and invalidates the cover spine width)
- text width is 5.5in --- body code blocks must fit within 70 monospace characters, code inside callouts within 60 (the tcolorbox icon column and padding eat the difference; a 61-char callout line touches the box frame)
- verbatim overflow produces no overfull warning in the LaTeX log --- check by counting characters in the markdown; emoji render roughly double width
- when a code line is too wide, first tighten the whitespace before aligned trailing `//` comments, then trim the comment text; restructure the code itself only as a last resort
- pandoc builds a raw PDF, then ghostscript post-processes it to:
    - flatten transparency (PDF 1.3 compatibility)
    - cap image resolution at 600 PPI
    - use lossless FlateEncode (not JPEG) to preserve exact colors
- dedication page after the title page (centered reader message)
- part divider pages with gorgo images for each subbook

## sc++-only interior (`sc++-lulu.pdf`)

- Gorgo Starting C++ alone at the same lulu executive trim as the combined interior (7x10in, same margins, 11pt, same 70/60 code line limits)
- sources: `../sc++/frontmatter.yaml`, the author intro, ch00--ch15, the sc++ bibliography, then `index.md`
- `index.md` holds the `\printindex` so the index renders at the very end, after the references
- `.lulu-sc-bib.md` is the sc++ bibliography with its own `\printindex` line stripped (otherwise the index would print twice); it is generated by make, do not edit it
- not built by `make all`; build it explicitly with `make sc++-lulu.pdf`

## c4c++-only interior (`c4c++-lulu.pdf`)

- Gorgo C for C++ Programmers alone at the same lulu executive trim as the combined interior (7x10in, same margins, 11pt, same 70/60 code line limits)
- sources: `../c4c++/frontmatter.yaml`, the author intro, ch00--ch12, the conclusion, appendix A, the c4c++ bibliography, then `index.md`
- `.lulu-c4-bib.md` is the c4c++ bibliography with its own `\printindex` line stripped (otherwise the index would print twice); it is generated by make, do not edit it
- not built by `make all`; build it explicitly with `make c4c++-lulu.pdf`

## cover (`lulu-cover.pdf`)

### template

the template PDF is `lulu-cover-template.pdf`. descriptions of the parts and measurements are in the template.

### content

- front cover: use the `c++c-gorgo-cover.png` image (background color `#0d1b2a` matched to the full-bleed cover background). title is `Gorgo Starting C++ and C`. subtitle is the date of the last commit. no author name on the front.
- spine: title centered, `Gorgo Books` (stacked small caps) at the base of the spine
- back cover: a cheetsheet with tables from the sc++ and c4c++ books:
    - printf format specifiers (c4c++ ch01)
    - bitwise operators (c4c++ ch04)
    - std::format specifiers (sc++ ch10)
    - operator precedence (c4c++ ch04)
    - common container methods (sc++ ch03 and ch08)
- back cover bottom left (x = 0.7in), clear of the ISBN barcode zone in the bottom-right corner: `https://gorgo.dev/cpp`

### cover image

`c++c-gorgo-cover.png` is a make target --- it is generated from `c++c-gorgo-with-badge.png` by flood-filling the white background with `#0d1b2a` (the full-bleed cover background color). spine width 1.106in for the 468-page interior; total trim with bleed: 15.356in x 10.25in --- if the interior page count changes, recompute the spine width and the layout offsets in the tex header.

## standalone sc++ cover (`lulu-cover-sc++.pdf`)

- wraparound cover for `sc++-lulu.pdf` built from `lulu-cover-sc++.tex`, same design language as the combined cover
- spine width 0.771in for the 318-page interior (lulu formula: 0.06 + pages x 0.002236); total trim with bleed: 15.021in x 10.25in --- if the interior page count changes, recompute the spine width and the layout offsets in the tex header
- front: `c++-gorgo.png` art (single C++ book with shield), title `Gorgo Starting C++`, commit-date subtitle, no author name
- `c++-gorgo-sc-cover.png` is a make target --- `c++-gorgo.png` pre-flattened onto `#0d1b2a` with the alpha channel removed; keeping the alpha makes ghostscript rasterize the entire page (vector text included) when flattening for PDF 1.3
- back cover cheatsheet, all sourced from sc++: escape sequences (ch01/ch03, replaces the combined cover's printf table), bit operators (ch07, binary examples), std::format specifiers (ch10), operator precedence (ch04), common container methods (ch03/ch08)
- URL bottom left of the back cover, clear of the ISBN barcode zone in the bottom-right corner, matching the combined cover

## standalone c4c++ cover (`lulu-cover-c4c++.pdf`)

- wraparound cover for `c4c++-lulu.pdf` built from `lulu-cover-c4c++.tex`, same design language as the other covers
- spine width 0.404in for the 154-page interior (lulu formula: 0.06 + pages x 0.002236); total trim with bleed: 14.654in x 10.25in --- if the interior page count changes, recompute the spine width and the layout offsets in the tex header
- front: `c-gorgo.png` art (single C book), title `Gorgo C for C++ Programmers`, commit-date subtitle, no author name
- `c-gorgo-c4-cover.png` is a make target --- `c-gorgo.png` pre-flattened onto `#0d1b2a` with the alpha channel removed, same reason as the sc++ cover
- back cover cheatsheet, all sourced from c4c++: printf format specifiers (ch01), bitwise operators (ch04), string.h functions (ch03), operator precedence (ch04), fopen modes (ch10)
- URL bottom left of the back cover, clear of the ISBN barcode zone in the bottom-right corner, matching the other covers

## lulu compliance

- no transparency in final PDFs (ghostscript flattens with `-dCompatibilityLevel=1.3`)
- image resolution capped at 600 PPI
- lossless image encoding to avoid color shifts between raster images and vector fills
