## Gorgo Starting C++

Start programming in modern C++ --- no experience required.

<b>Gorgo Starting C++</b> takes you from your very first program to writing real code with the features working C++ developers use today: std::println, std::format, std::vector, and std::expected. Each chapter builds on the last --- variables, strings, expressions, control flow, functions, numbers and bits, containers, streams and files, exceptions, and move semantics.

Short <i>Try It</i> programs get your hands on the keyboard early and often. <i>Key Points</i> recap what matters. Every chapter ends with exercises that test your understanding, from predict-the-output puzzles to find-the-bug challenges. <i>Tip</i>, <i>Trap</i>, and <i>Wut</i> callouts highlight the idioms worth copying, the mistakes everyone makes once, and the rules nobody expects.

Written for introductory programming classes and self-learners alike, with a tone that stays light without talking down to you.

This book is open source. The complete text is available at https://gorgo.dev/cpp.

## Gorgo C for C++ Programmers

You know C++. How hard can C be? Harder than you think --- and easier, once someone shows you where the two languages genuinely differ.

<b>Gorgo C for C++ Programmers</b> is a focused guide that maps what you already know onto C: printf and scanf instead of iostreams, char arrays and string.h instead of std::string, malloc and free instead of new and delete, return codes and goto cleanup instead of exceptions, function pointers instead of lambdas. It also covers the ground C++ never made you walk: pointer arithmetic, memory layout, low-level I/O with file descriptors, extern "C" linkage, and the preprocessor macro system.

Short <i>Try It</i> programs, <i>Key Points</i>, and end-of-chapter exercises keep the learning hands-on, while <i>Tip</i>, <i>Trap</i>, and <i>Wut</i> callouts flag the idioms to adopt and the traps that bite C++ programmers hardest.

This book is open source. The complete text is available at https://gorgo.dev/cpp.

## Gorgo Starting C++ and C

Two books in one volume: a complete introduction to modern C++, and a practical guide to C for the C++ programmer you are about to become.

Part one, <b>Starting C++</b>, assumes no programming experience and takes you from your first program to real code with std::println, std::format, std::vector, exceptions, and move semantics --- covering variables, strings, expressions, control flow, functions, numbers and bits, containers, and file I/O along the way.

Part two, <b>C for C++ Programmers</b>, builds on that foundation and maps it onto C: printf and scanf, char arrays and string.h, malloc and free, pointer arithmetic, low-level I/O, goto cleanup, extern "C", and the preprocessor macro system.

Throughout, <i>Try It</i> programs get your hands on the keyboard, <i>Key Points</i> recap each chapter, exercises test your understanding, and <i>Tip</i>, <i>Trap</i>, and <i>Wut</i> callouts flag the idioms worth copying and the mistakes everyone makes once.

This book is open source. The complete text is available at https://gorgo.dev/cpp.
